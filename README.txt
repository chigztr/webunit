WEBUNIT — BRAND NEW RESPONSIVE LAYOUT
=====================================

This is a full redesign, not another patch of the old mockup.

DESIGN PRINCIPLES
-----------------
- No floating/overlapping hero elements.
- The supplied Chigz + tech artwork is displayed in full, not aggressively cropped.
- YouTube statistics live in their own stable row below the hero.
- Desktop and mobile use the same content order.
- Larger readable typography throughout.
- One featured Today's Deal followed by supporting deal cards.
- Chigz Picks has its own dark editorial section.
- Clear visual separation for Smartphones, Creator Gear and Home Tech.
- Search remains functional.
- Static Image / YouTube Video card modes remain functional.
- Affiliate links and review links remain functional.
- Manual subscriber and total-view counts remain editable in CMS.
- Hero/section/footer text remains editable in CMS.
- Optional Hero Feature Image remains editable in CMS.

----------------

- style.css
- app.js
- admin/config.yml
