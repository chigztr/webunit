WEBUNIT FULL REPLACEMENT

This package is a full site bundle for your WebUnit website.

Contents include:
- index.html
- style.css
- app.js
- admin/
- settings.json
- products.json
- images/chigz-banner.png
- favicon.svg
- _headers (if present)

How to use:
1. Back up your current site files first.
2. Replace the site files with everything in this folder.
3. Commit/upload and redeploy.
4. If you use the CMS, you can then edit:
   - YouTube subscriber count
   - YouTube total views
   - Top strip channel link/label
   - Brand banner image

Important:
- This bundle includes settings.json and products.json based on the latest available local copy in this workspace.
- If your live site has newer content in those two files, keep your own versions instead of overwriting them.
